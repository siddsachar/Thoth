# Skills Hub

Skills are instruction packs that teach Row-Bot how to approach a category of work. Skills Hub is where you browse installed skills, inspect details, enable or disable them, pin useful ones, and create or edit local skills. Enabled skills can also be discovered and loaded progressively when a task clearly matches their purpose.

## UI Walkthrough

- **Browse/search** finds bundled, installed, local, and external-source skills.
- **Filters** narrow by source, installed state, or task type.
- **Skill detail** explains purpose, instructions, source, and status.
- **Enable/disable** decides whether Row-Bot may use the skill.
- **Pin** keeps an important skill easy to reach.
- **Create/edit** lets you maintain a local skill for your own workflow.

## Creating A Skill

1. Decide what task the skill should help with.
2. Write concise instructions, examples, and boundaries.
3. Include when the skill should and should not be used.
4. Save it locally.
5. Enable it and test with a small prompt.
6. Revise if Row-Bot overuses or misunderstands it.

## What Skills Change

Skills shape Row-Bot's behavior; they do not automatically grant credentials or bypass approvals. A skill can make Row-Bot more consistent for a task, but tools still need to be enabled and approved where appropriate.

## Automatic Selection

When progressive discovery is available, Row-Bot can search enabled skills and load a relevant one for the current task. A successful automatic load appears once as **Using _skill_** and adds an active skill chip.

- Automatically selected skills are stored per parent task or child Agent, not per shared Agent Profile.
- Reopening a task restores its selected skills.
- Parent tasks and sibling children do not share automatic activation state.
- Up to five automatically selected skills are retained per task; pinned skills remain separate.
- Loading an already active skill does not add a duplicate receipt.

Automatic selection changes instructions only. It cannot add a denied tool, alter credentials, bypass approvals, expand a workspace, or change an Agent Profile. Read [Progressive Tools And Skills](/docs/guides/progressive-tools-and-skills) for the complete tool and skill flow.

## Troubleshooting

- If a skill is not used, make your prompt match its purpose and confirm it is enabled.
- If a skill is too aggressive, disable or rewrite it with clearer boundaries.
- If an external skill is unfamiliar, inspect it before enabling.
