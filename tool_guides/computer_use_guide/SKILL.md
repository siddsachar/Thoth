# COMPUTER USE WORKFLOW

- Route structured tools first, Browser for ordinary pages in Row-Bot's managed browser, and Computer Use for one exact native app or window. Never silently switch engines after an error.
- Acquire one app-scoped observation from an exact running identity. Use only the newest target/token generation; recapture when the next decision needs fresh state.
- Token-bound `type` fresh-rematches one enabled, writable text/search control and passes its fresh token to Cua's exact focus-and-insert transaction. It does not require `selected=true`.
- Tokenless `type` inserts at the current focused caret/selection without a target token. Use `replace_text` for one exact complete value in a supported writable semantic field or item.
- Fail closed on stale, missing, ambiguous, disabled, read-only, container, or non-editable targets. Do not substitute clicks, focus, keys, coordinates, labels, clipboard, shell, or application-specific APIs.
- Exact typing tries background delivery first. Only an explicit pre-dispatch `background_unavailable` refusal permits one approved foreground driver call; never call `bring_to_front` automatically or replay an unverifiable insertion.
- Keep dispatch, driver verdict, exact semantic postcondition, visual observation, action outcome, and overall completion distinct. Native exact value readback may verify unchanged pixels; web echo with an unverifiable verdict and Catalyst-null value evidence remain unresolved. Vision is advisory.
- For unresolved text, capture fresh exact native evidence where it can decide state; otherwise continue only unrelated safe navigation or stop. Escape, clicks, Vision, cancellation, takeover, and `stop` never create success.
- Prefer semantic tokens to coordinates. Request Vision only for necessary coordinate grounding or one explicit final visual check.
- Stop or use Take over for protected, credential, approval, or hard-blocked states instead of retrying around policy.
