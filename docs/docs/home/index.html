Home

Home is the launch area for Row-Bot's major work surfaces. It is not meant to replace the detailed guides. Use Home to see current state and start work quickly, then open the dedicated page when you need a walkthrough.

Home Tabs​

  • Workflows is the entry point for saved automations.
  • Designer starts design projects and opens Designer Studio.
  • Developer connects code workspaces and opens Developer Studio.
  • Knowledge reviews local memory, documents, and graph records.
  • Monitor shows logs, journals, channel state, and background activity.
