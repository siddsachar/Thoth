Row-Bot 4.6.0 architecture overview

Architecture

How Row-Bot stays local-first.

These high-level subsystem maps sit inside Row-Bot's 4.6 control plane: one checkpointed parent coordinates agent work, documents enter a bounded durable pipeline, and authenticated browsers share one owner authority. Durable state stays with the host; models, tools, network routes, and optional runtimes remain explicit.

Explore diagrams Read technical reference
Durable local state

Conversations, orchestration checkpoints, documents, memory, tasks, access records, and project assets live with the Row-Bot host.

Parent-led work

One authoritative parent joins required results, tracks dependencies and later waves, and finalizes once across retries, approvals, and restarts.

One owner authority

Local desktop, remote desktop, and compact sessions expose the same owner capability behind invitations, revocable sessions, exact origins, and host checks.

Explicit external routes

Hosted models, tools, channels, MCP, Computer Use, Tailscale, and reverse proxies remain separately configured, reviewable, and approval-aware.
